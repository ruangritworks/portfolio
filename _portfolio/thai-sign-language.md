**Senior project · Bangkok University**

## Objective

Develop a machine learning system that recognizes Thai sign language gestures using webcam input.

## My contribution

- Developed the gesture recognition system.
- Used MediaPipe for hand landmark detection.
- Trained and optimized the model to improve recognition performance.

## Approach

The system used webcam input and MediaPipe hand landmark detection to support machine learning-based gesture recognition.

**Technology:** MediaPipe, Machine Learning.

**Focus:** Hand landmark detection, model training, model optimization.
